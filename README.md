# React + Vite


- Features of this site
    
- This project hase two part. First part is client side which is made by react JS firebase authentication system react router. Second part is backend which made by expressJs server side with mongoDB Database.

- This website is build for Atuomobile Brand-Shop limited.

- There are many kind of functionality in this website.

1. User email authentication using firebase.
2. User can login with gmail account
3. There are 2 private routes.The two private routes are addProduct rout and myCart route. Only when you will login you can access these private routes.
4. User Can see every brand items details, rating, price if they are login.
5. User can Add a new product and update any existing product. 
6. User can choose his/her products and add product in his cart and he/she can see that products those he/she has addedd his/him cart. User can delete his/ her product from his/ her cart.
